# EAHS Research Club

Website for the Easton Area High School Research Club.

## Pages

- `index.html` — Home
- `about.html` — About the club, project types, board, and FAQs
- `research.html` — Archive for released member research
- `join.html` — Membership, meetings, expectations, and FAQs

## Publishing

This is a static HTML site and can be hosted directly with GitHub Pages.
